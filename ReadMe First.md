## **Project Title: Seatify – Event Booking Website**

---

## **Project Description**

For my final project, I developed **Seatify**, a multi-page event booking website designed to simulate a real-world platform where users can explore live performances and reserve tickets. I chose this idea because it connects with my experience working in event promotion and allows me to create something practical and realistic rather than just a basic website.

The goal of the project was to design a clean, user-friendly interface that highlights events such as concerts, theater performances, and festivals, while also providing a simple and secure booking experience. The website focuses on presenting events in a visually appealing way and building trust with users through clear messaging and structured navigation.

---

## **Technical Implementation**

The project was built using **HTML, CSS, and JavaScript**, following the requirements of the assignment:

* **HTML (Structure):**
  The website includes multiple pages such as Home, Events, Event Details, Booking, and Contact. Each page is structured using semantic HTML elements to ensure clarity and organization.

* **CSS (Styling):**
  A consistent visual style was applied across all pages, using a dark, cinematic theme with accent colors to create a modern and professional appearance. Layouts were built using Flexbox and Grid, and the design is responsive for different screen sizes.

* **Web Forms (Validation):**
  The booking and contact pages include forms with required fields such as name, email, and ticket selection. Validation is implemented using both HTML5 attributes and JavaScript to ensure users enter correct and complete information.

* **JavaScript (Functionality):**
  JavaScript is used to enhance interactivity, including form validation, dynamic ticket price calculation, event filtering, and user feedback messages after submission.

* **Audio/Video:**
  A background video is included on the homepage to create a more immersive and engaging experience, reinforcing the theme of live performances and events.

## **Project Files**

* `index.html` - homepage with the hero section, featured performances, and benefits section
* `events.html` - events listing with category filters and live status text
* `jazz-night-details.html` - detail page for Jazz Night Live
* `shakespearian-play-details.html` - detail page for Shakespearian Play
* `summer-rock-fest-details.html` - detail page for Summer Rock Fest
* `skyline-acoustic-session-details.html` - detail page for Skyline Acoustic Session
* `booking.html` - ticket booking form with live pricing and validation
* `contact.html` - contact page with support details and message form
* `css/styles.css` - shared responsive styling
* `js/script.js` - shared JavaScript for navigation, filters, pricing, and validation
* `images/` - local artwork and media used across the site

---

## **How to Open**

To run the project, open `index.html` in a web browser. You can also use a local development server if you prefer. From there, use the navigation menu to move between pages and test the booking and contact forms.
